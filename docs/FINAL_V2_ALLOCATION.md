# Group 19 최종 재분배 분석 v2 (2025-09, 총량 고정 버전)

## 1. 이 버전이 이전 `ttareungi_redistribution_summary`와 다른 점
| 항목 | 이전 | v2 |
|---|---|---|
| 총량 | 합계 −9.7천 대/일 (재분배가 아님) | 합계 **0** (보유량 고정, 정수 단위로도 0) |
| 상한 | 0.8 × 명목 거치대 (재고의 39%가 거치대 초과) | 유효 상한 = max(거치대, min(재고 95퍼센타일, 1.5×거치대)) |

| 신뢰도 | 없음 | 민감도 5종의 부호 일치 + 데이터 플래그로 HIGH/MEDIUM/LOW |

## 2. 방법
1. 대여소 × (평일/주말)로 집계한다. D = 예측 일수요(평균), B = 0시 재고(평균), u = 정상일 기준 자전거 1대당 하루 대여 횟수.
2. 필요량 need_i = D_i / clip(u_i, 0.5, 24).
3. 배분 풀의 보유량 N = Σ B_i (풀 안의 대여소만). 목표 t_i = min(U_i, λ·need_i), 합계가 N이 되도록 λ를 이분법으로 구한다.
4. 목표와 현재 재고를 모두 최대잉여법으로 정수화하여 Σ(이동) = 0을 유지한다.
5. 이동량 = 목표 − 현재(정수).

## 3. 핵심 결과 (평일 / 주말)
- 배분 대상 대여소: 2,472 / 2,470곳. 제외: 미가동 39, 데이터 확인 필요 182 / 183, 상암센터·수리센터 2.
- 보유량 26,638 / 27,836대 중 이동이 필요한 자전거: 4,874 / 4,206대 (**18.3% / 15.1%**).
- 보유량은 필요량(안전계수 1.0)의 68% / 76%에 그친다. 즉 "남는 자전거"는 없고 재분배는 부족을 줄이는 수단일 뿐이다.
- 추가 대상은 평균 품절률 22.2%, 회수 대상은 2.4%이다 (스피어만 상관 0.82).
- 신뢰도 HIGH: 367행 (평일 247, 주말 120). 대부분 MEDIUM이므로 발표에서는 HIGH 위주로 사례를 든다.

## 4. 반드시 지켜야 할 해석상의 한계
1. **이 결과는 수요 비례성 검정이 아니다.** 이동량과 예측 수요의 상관은 약 0.02(스피어만)이다. 이동량은 "평소 재고가 정상일 대비 얼마나 부족한가", 즉 품절 압력을 반영한다. 가설검정은 카이제곱 적합도·회귀(지도 A, C)에서 한다.
2. **품절률과의 상관은 일부 기계적이다.** 회전율을 정상일로만 구하고 재고에는 품절일이 섞이기 때문이다. 타당성 근거로 단독 인용하지 않는다.
3. **0시 재고는 일중 재배치를 반영하지 못한다.** 마곡나루역 2번 출구처럼 하루 대여 600건 이상인데 0시 재고가 1대인 거점이 있다. 회전율이 24를 넘는 행은 LOW로 표시했다.
4. **거치대 수와 재고 컬럼이 서로 맞지 않는다.** 대여소 중앙값 기준 재고/거치대가 1.2를 넘는 곳이 많다(`STOCK_EXCEEDS_DOCKS`). 원인(거치대 수 오래됨, QR 거치, 컬럼 정의 등)은 아직 확인되지 않았으므로 상한은 임의의 소프트 값(1.5배)이다. 목표의 약 38%가 명목 거치대를 넘는다 (`TARGET_ABOVE_NOMINAL_DOCKS`).
5. **예측 수요 대체 행이 630행(회귀 대체 + 시스템 중앙값 회전율)** 있다. 대부분 품절이 잦은 대여소라서 방향은 타당하지만 대수는 근거가 약하다.
6. 한 달(2025-09) 자료이며 계절성은 반영하지 않았다.

## 5. 민감도 (기본 대비 부호 일치율)
회전율 상한 12: 97.9% · 상한 없음: 99.5% · 수요 + 30분 품절 보정: 97.8% · 거치대 상한 없음: 87.2%.
